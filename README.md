JavaScript sentence boundary detection ported from pySBD

## Installation

```bash
npm install @coloop-ai/jssbd
```

## Usage

```ts
import {} from '@coloop-ai/jssbd'
```

## Development

```bash
pnpm install
pnpm run build     # Build the package
pnpm run tc        # Type-check
pnpm run lint      # Lint
pnpm run test      # Run tests
pnpm run format    # Check formatting
```

New dependency versions must wait seven days before pnpm can install them. This is configured in `pnpm-workspace.yaml` as a supply-chain safety delay.
